
# 🟡 Pac-Man - Code.org

## 📖 Sobre o projeto

Este projeto consiste em uma recriação do clássico **Pac-Man**, desenvolvida utilizando o ambiente **Game Lab** do **Code.org**. O objetivo foi aplicar os conceitos de lógica de programação aprendidos durante o curso, criando um jogo interativo com movimentação, colisões e coleta de pontos.

O jogador controla o Pac-Man pelo labirinto, coletando os alimentos espalhados pelo mapa enquanto evita obstáculos e desafios presentes durante a partida.

---

## 🎯 Objetivos

- Praticar lógica de programação.
- Desenvolver um jogo utilizando Game Lab.
- Trabalhar com eventos do teclado.
- Utilizar sprites e animações.
- Implementar detecção de colisão.
- Organizar o código utilizando funções.

---

## 🛠️ Tecnologias utilizadas

- Code.org Game Lab
- JavaScript

---

## 📚 Conceitos aplicados

- Variáveis
- Condicionais (`if` e `else`)
- Funções
- Loops
- Sprites
- Movimentação de personagens
- Detecção de colisões
- Controle por teclado
- Organização do código

---

## 🎮 Como jogar

- Utilize as **setas do teclado** para mover o Pac-Man.
- Colete todos os alimentos espalhados pelo cenário.
- Evite obstáculos durante a partida.
- Tente alcançar a maior pontuação possível.
