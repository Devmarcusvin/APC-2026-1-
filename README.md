## Semanas 15 e 16

# 🚀 Projeto Final

### EduCA-DF – Explorador Educacional da PDAD 2024

Como atividade final da disciplina foi desenvolvido um sistema em Python utilizando Tkinter para exploração de microdados da **PDAD 2024**.

### Tema escolhido

**Perfil Educacional por Região Administrativa do Distrito Federal**

### Funcionalidades implementadas

- Interface gráfica com Tkinter;
- Filtros interativos;
- Estatísticas descritivas;
- Gráficos utilizando Matplotlib;
- Tratamento de valores especiais (99999 e 88888);
- Exportação de resultados em CSV;
- Exportação de relatórios em TXT;
- Análise por Região Administrativa.

### Dados utilizados

- PDAD_2024-Moradores.csv
- PDAD_2024-Domicílios.xlsx

Disponíveis em:

https://pdad.ipe.df.gov.br/
