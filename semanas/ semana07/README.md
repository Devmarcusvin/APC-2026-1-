# Relatório de Aprendizagem – Lições 07 a 10

## Introdução

Entre as **Lições 07 e 10** foram estudados conteúdos fundamentais para o desenvolvimento de jogos no Game Lab do Code.org. Nesse período, os exercícios passaram a envolver maior interação entre os elementos da tela, utilizando animações, movimentação automática de sprites e estruturas condicionais para alterar comportamentos durante a execução do programa.

O principal objetivo dessas lições foi compreender como controlar objetos de forma dinâmica, permitindo que personagens mudem de posição, executem ações automáticas e reajam a determinadas condições definidas no código.
